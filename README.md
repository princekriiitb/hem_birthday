# 🎂 Happy Birthday Hemshree
A multi-page birthday website made with HTML, CSS and JavaScript.

## Pages
- `index.html` — home
- `wishes.html` — wishes
- `memories.html` — photo gallery
- `letter.html` — birthday letter
- `style.css` — styling
- `script.js` — confetti effect
- `assets/` — photos

## GitHub Pages
1. Create a GitHub repository, for example `hemshree-birthday`.
2. Upload every file **and the assets folder**.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch → main → /(root)** and save.
5. GitHub will provide the public URL.

Keep the folder structure unchanged.
